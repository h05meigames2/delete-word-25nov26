# The Word You'd Delete From the Dictionary

The word I would erase from the dictionary forever is **dictionary**. Once it is gone, the dictionary can no longer name itself — every copy becomes a book with no word for what it is. The joke is the deletion itself: remove the one word that defines the whole book, and the book forgets what it is.

## Run it

```sh
python3 main.py
```

This writes the single word to `/output/entry.txt`.
